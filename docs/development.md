# 开发记录

## 题库和教程

四份算法题单按原始题序保存，同一题在多个题单中复用同一份站内练习。算法支持函数接口和标准输入输出，链表和树使用 Python 节点接口。有多个合法答案的题目使用对应的有效性判定。AI 工程题将可执行用例和人工评阅要点放在同一页，用于同时练习功能正确性与设计说明。[资源调研](survey.md) · [练习讲解](practice-guide.md)

教程将原文资料、中文讲解和对应的练习关联起来。本机讨论保存当前题目或教程 ID，可以针对同一篇教程继续提问，也可以选择原文链接和引用片段。

## 浏览器运行与个人数据

网页版和本机版复用界面、题库和记录模型。GitHub Pages 通过相对路径加载静态内容。Python 在 Web Worker 中执行，函数题支持自定义判题，标准输入输出题按用例创建独立解释器。遇到死循环时，页面终止该次执行。PyTorch 题保留题面、代码编辑、参考解与本机评测入口。

草稿和评测使用本地事件记录，网页存 IndexedDB，本机服务保存在项目的数据目录。JSON 备份使用事件 ID 合并，支持从网页切换到本机或在两台设备间迁移。需要远程同步时，由本机服务向用户指定的 GitHub 私库写入。公开仓库分为 main 源码分支和 gh-pages 静态发布分支。

## 验证

在真实 Chromium 浏览器中，407 道浏览器题的参考解通过 1,518 个用例。覆盖函数题、自定义多解、标准输入输出、NumPy 和超时。PyTorch 题使用本机解释器。浏览器进度测试覆盖刷新恢复、并发写入、导出下载、跨浏览器导入和重复导入；私库同步测试使用独立的测试记录。
